# Сайт для папы

Файлы сайта:
- `index.html` — содержимое страницы
- `style.css` — оформление
- `script.js` — анимации и кнопка послания

## Публикация на GitHub Pages
1. Создай новый репозиторий на GitHub, например `site-for-dad`.
2. Загрузи в репозиторий все три файла (не сам ZIP).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Через минуту-две GitHub Pages покажет ссылку на сайт в разделе Pages.

Чтобы персонализировать письмо, отредактируй текст в `index.html`.
